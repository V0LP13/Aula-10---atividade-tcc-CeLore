# CeLore DMS — página Motocicletas

## Arquivos
- `motocicletas.html`: estrutura da tela.
- `motocicletas.css`: estilos responsivos.
- `motocicletas.js`: cadastro, listagem, busca, edição, exclusão e persistência local.

## Como testar
1. Coloque os três arquivos na mesma pasta do projeto.
2. Abra `motocicletas.html` no navegador (ou use a extensão Live Server no VS Code).
3. Cadastre, edite, busque e exclua motocicletas.
4. Os dados ficam no `localStorage` deste navegador.

## Como integrar ao CeLore existente
1. Faça uma cópia/commit do projeto antes de alterar.
2. Copie o conteúdo do `<main class="main-content">...</main>` para a área principal da página atual.
3. Não duplique o `<aside class="sidebar">`: mantenha o menu existente. Deixe o link Motocicletas com a classe `active`.
4. Adicione `<link rel="stylesheet" href="motocicletas.css">` no `<head>` da página.
5. Adicione `<script src="motocicletas.js"></script>` antes de `</body>`.
6. Se o projeto já importa Font Awesome, remova o segundo link do CDN no HTML para não duplicar a importação.
7. Ajuste os caminhos dos links de menu (`index.html`, `clientes.html`, `vendas.html`) aos nomes reais do seu projeto.

## Limitação importante
`localStorage` é apenas uma etapa de protótipo: os dados ficam no navegador e não são compartilhados com outros usuários ou computadores. Para o TCC funcionar como sistema real, crie endpoints no backend e salve os registros em banco de dados. Não use `localStorage` para autenticação nem para dados sensíveis.
